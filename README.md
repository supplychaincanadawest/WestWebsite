# WestWebsite

Supply Chain Canada West — professional website for supply chain services, events, and resources in Western Canada.

## Live Site
[west-website.vercel.app](https://west-website.vercel.app)

## Repository Structure

| File / Folder | Description |
|---|---|
| `index.html` | Homepage — main landing page |
| `about.html` | About page — mission, team, and background |
| `events.html` | Events page — upcoming supply chain events |
| `assets/` | Images, icons, and static media |
| `uploads/` | User-uploaded or dynamic content files |
| `events/` | Event-specific content and detail pages |
| `vercel.json` | Vercel deployment config (cache + security headers) |
| `sitemap.xml` | XML sitemap for SEO indexing |
| `robots.txt` | Crawler directives for search engines |
| `manifest.webmanifest` | PWA manifest for installable web app support |

## Deployment
Hosted on [Vercel](https://vercel.com). Every push to `main` triggers an automatic production deployment.

## MCP / Claude Integration
This repository is configured for Claude Code (MCP) access via a Fine-grained Personal Access Token with `Contents` (Read & Write) and `Metadata` (Read) permissions scoped to this repository.
